# Master V1.1 — Rediseño del administrador principal

Esta actualización modifica únicamente la experiencia visual del administrador principal.

- Dashboard exclusivo del dueño con jerarquía operativa.
- Oculta en el inicio del dueño las tarjetas grandes duplicadas del dashboard legado.
- Centro de control con KPIs accionables, atención prioritaria y accesos rápidos.
- Gestión compacta de usuarios, productos, inventario, pedidos, reportes, saldo, paneles y rentabilidad.
- Conserva las vistas actuales de vendedores, distribuidores y administradores rentados.
- No modifica base de datos ni endpoints de Master V1.
- Libro de saldo y bitácora administrativa continúan dentro del área Admin.
