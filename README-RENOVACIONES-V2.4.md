# Servicios Digitales Peters — Renovaciones v2.4

## Corrección
Se agregó el acceso visible **🔄 Renovaciones** para vendedores y distribuidores dentro del dashboard.

## Funciones
- Lista cuentas propias entregadas cuyos productos tienen `renewable=1`.
- Muestra días restantes, vencimiento, correo, perfil y pedido original.
- Muestra precio y días configurados por producto.
- Permite renovar con descuento de saldo.
- Extiende el vencimiento desde la fecha de vencimiento actual.
- Bloquea la renovación si quedan menos de 1 día.
- Registra el movimiento de saldo como `renovacion`.
- El administrador controla la disponibilidad desde el producto.
- Se agregan `renewable` y `renewal_days` al listado administrativo de productos.
